<b>Mental Model Shift: Names vs. Boxes</b><br/>
In many traditional programming languages like C or C++, developers learn to think of a variable as a labeled physical box in memory. When you assign a value, you put the value into the box. If you assign a new value, you throw away the contents of the box and put something else in.<br/><br/>

<b>In Python, this mental model will cause severe bugs.</b><br/>
In Python, <b>variables are tags or sticky notes attached to objects in memory</b>, not physical boxes. The object exists independently in Python's memory heap, and a variable name is simply a reference pointing to that object.<br/><br/>

<b>Real-World Analogy:</b><br/>
Imagine a warehouse storage container containing package <code>"PKG-8812"</code>. Instead of moving the entire physical cargo every time someone wants to track it, workers attach sticky notes labeled <code>active_shipment</code>, <code>priority_item</code>, and <code>driver_assignment</code> to the container. The container is the <b>object in memory</b>; the sticky notes are <b>variable names</b> pointing to it.<br/><br/>

<b>Why does this matter?</b><br/>
1. <b>Multiple Names, One Object:</b> If you assign <code>a = [1, 2, 3]</code> and then <code>b = a</code>, you did <i>not</i> make a copy of the list. You attached a second sticky note (<code>b</code>) to the exact same list object in memory.<br/>
2. <b>Rebinding:</b> Reassigning a variable (<code>x = 20</code>) does not overwrite the old value <code>10</code>. It simply peels the sticky note <code>x</code> off the object <code>10</code> and sticks it onto a newly created object <code>20</code>. If no other names point to <code>10</code>, Python's Garbage Collector reclaims its memory.<br/>
3. <b>Memory Efficiency:</b> Python reuses small immutable objects (like numbers between -5 and 256 or short strings) across different variable names through internal optimization called <i>interning</i>.

def parse_package_count(raw_value: str, default: int = 1) -> int:
    \"\"\"
    Safely attempts to convert an input string to an integer count.
    Returns the default value if parsing fails.
    \"\"\"
    if not raw_value or not raw_value.strip():
        return default
        
    try:
        return int(raw_value.strip())
    except ValueError:
        print(f"Warning: Unable to parse '{raw_value}' as integer. Falling back to default: {default}")
        return default

print("\n--- INTERMEDIATE: Safe Parser Testing ---")

def ingest_raw_package_payload(payload: dict) -> dict:
    \"\"\"
    Sanitizes and converts raw external payload string dictionary into typed 
    domain values suitable for logistics calculations.
    \"\"\"
    print("\n--- ADVANCED: External Payload Ingestion & Validation ---")
    
    errors = []
    sanitized_data = {}
    
    # 1. Parse Tracking ID (String validation)
    raw_id = payload.get("tracking_id", "")
    if isinstance(raw_id, str) and raw_id.strip():
        sanitized_data["tracking_id"] = raw_id.strip().upper()
    else:
        errors.append("Invalid or missing 'tracking_id'.")
        
    # 2. Parse Weight (Float validation)
    try:
        raw_weight = payload.get("weight")
        weight_val = float(raw_weight)
        if weight_val <= 0:
            errors.append("Weight must be greater than zero.")
        else:
            sanitized_data["weight_lbs"] = weight_val
    except (ValueError, TypeError):
        errors.append(f"Invalid weight format: '{payload.get('weight')}'")

    # 3. Parse Priority (Boolean string conversion)
    raw_priority = str(payload.get("is_priority", "")).lower().strip()
    sanitized_data["is_priority"] = raw_priority in ["true", "1", "yes"]

    if errors:
        return {"success": False, "errors": errors}
        
    return {"success": True, "data": sanitized_data}
