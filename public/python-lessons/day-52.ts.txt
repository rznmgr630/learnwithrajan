<b>The Cache-Aside Lifecycle:</b>
<ol>

      <li>Write the result to Redis with a **Time-To-Live (TTL)**.</li>
      <li>Return the database result to the user.</li>

  </li>
</ol>

<b>Precision Traffic Throttling across Distributed Nodes</b><br/>
Fixed-window rate limiters suffer from boundary bursts (e.g., receiving 100 requests at 00:59 and 100 requests at 01:01).<br/><br/>

A **Sliding-Window Log** using Redis **Sorted Sets (`ZSet`)** tracks individual request timestamps with high precision, removing timestamps older than the active window.<br/><br/>

<b>Sliding Window Algorithm (`ZSet`):</b>
<ol>
  <li>Key: <code>ratelimit:sliding:{client_ip}</code>.</li>
  <li>Member & Score: Current Unix timestamp (<code>time.time()</code>).</li>
  <li><b>Step 1:</b> Remove entries older than <code>now - window_seconds</code> using <code>ZREMRANGEBYSCORE</code>.</li>
  <li><b>Step 2:</b> Count active requests using <code>ZCARD</code>.</li>
  <li><b>Step 3:</b> If count $< \text{max\_requests}$, add current request timestamp using <code>ZADD</code> and set TTL (<code>EXPIRE</code>). Allow request.</li>
  <li><b>Step 4:</b> If count $\ge \text{max\_requests}$, reject request (`HTTP 429 Too Many Requests`).</li>
</ol>

# ==============================================================================
# LESSON 4: Sliding-Window Rate Limiter with Redis ZSet
# ==============================================================================

import time
import redis
from fastapi import HTTPException, status

r = redis.Redis(host="localhost", port=6379, db=0, decode_responses=True)

def check_sliding_window_rate_limit(
    client_id: str,
    max_requests: int = 3,
    window_sec: int = 10
) -> bool:
    """Enforces sliding-window rate limiting using Redis Sorted Sets."""
    key = f"ratelimit:sliding:{client_id}"
    now = time.time()
    clear_before = now - window_sec

    # Execute atomically via Redis Pipeline
    pipe = r.pipeline()
    pipe.zremrangebyscore(key, 0, clear_before)  # 1. Purge expired log entries
    pipe.zcard(key)                              # 2. Count remaining active requests
    pipe.zadd(key, {str(now): now})               # 3. Add current request
    pipe.expire(key, window_sec)                 # 4. Refresh key TTL
    results = pipe.execute()

    active_request_count = results[1]

    if active_request_count >= max_requests:
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail=f"Rate limit exceeded ({max_requests} req / {window_sec}s).",
            headers={"Retry-After": str(window_sec)}
        )
    return True

print("--- LESSON 4: Sliding-Window Rate Limiter Configured ---")
print("Algorithm: Redis ZSet Pipeline with ZREMRANGEBYSCORE and ZCARD.")
