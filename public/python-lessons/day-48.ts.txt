<b>Browser Security Boundaries and Credential Isolation</b><br/>
Web browsers enforce strict security boundaries to isolate websites from one another. Understanding how **CORS**, **CSRF**, and **Secure Cookies** interact is essential for building safe web APIs.<br/><br/>

<b>1. Cross-Origin Resource Sharing (CORS):</b><br/>
CORS is an HTTP-header-based mechanism that allows a server to indicate which external origin domains (e.g., <code>https://dashboard.company.com</code>) are permitted to read resources.<br/>
<i>Production Rule:</i> Never use <code>allow_origins=["*"]</code> in production when using authenticated credentials! Explicitly declare allowed domain origins.<br/><br/>

<b>2. Cross-Site Request Forgery (CSRF):</b><br/>
CSRF occurs when a malicious website causes a victim's web browser to perform an unwanted action on a trusted site where the user is currently authenticated.<br/>
<i>How it happens:</i> Browsers automatically attach session cookies to outbound HTTP requests matching the target domain. If a user visits \`evil.com\`, a hidden form on \`evil.com\` can submit a \`POST\` request to \`bank.com/transfer\` using the user's active session cookie!<br/><br/>

  <li><code>SameSite=Lax</code> (or <code>Strict</code>): Prevents the browser from sending the cookie on cross-site requests, mitigating CSRF attacks!</li>
</ul>

# LESSON 3: Rate Limiting & DoS Throttling Implementation

import time
from fastapi import FastAPI, Request, HTTPException, status

app = FastAPI()

# ------------------------------------------------------------------------------
# In-Memory Fixed Window Rate Limiter Class (Production uses Redis)
# ------------------------------------------------------------------------------

class RateLimiter:
    """Simple rate limiter enforcing request thresholds per IP address."""
    def __init__(self, max_requests: int = 5, window_seconds: int = 60):
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self._client_records: dict[str, list[float]] = {}

    def is_rate_limited(self, client_ip: str) -> tuple[bool, int]:
        now = time.time()
        timestamps = self._client_records.get(client_ip, [])

        # Filter timestamps within active window
        valid_timestamps = [ts for ts in timestamps if now - ts < self.window_seconds]
        self._client_records[client_ip] = valid_timestamps

        if len(valid_timestamps) >= self.max_requests:
            return True, 0

        valid_timestamps.append(now)
        remaining = self.max_requests - len(valid_timestamps)
        return False, remaining

limiter = RateLimiter(max_requests=3, window_seconds=10)


@app.get("/api/v1/throttled-data")
async def read_throttled_endpoint(request: Request):
    client_ip = request.client.host if request.client else "127.0.0.1"

    is_limited, remaining = limiter.is_rate_limited(client_ip)
    if is_limited:
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail="Rate limit exceeded. Max 3 requests per 10 seconds.",
            headers={"Retry-After": "10"}
        )

    return {"status": "SUCCESS", "client_ip": client_ip, "remaining_quota": remaining}
