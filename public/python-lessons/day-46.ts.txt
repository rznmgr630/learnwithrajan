<b>Decoupling HTTP Transport from Domain Business Logic</b><br/>
When building small proof-of-concept scripts, placing database queries, Pydantic validation, business rules, and HTTP endpoint decorators in a single file works fine. However, as enterprise applications grow to hundreds of endpoints, monolithic file structures become unmaintainable.<br/><br/>

<b>Separation of Concerns (SoC)</b> is the architectural principle of dividing a software application into distinct layers, where each layer has a single, well-defined responsibility:<br/><br/>

<b>1. The 4 Core Architectural Layers:</b>
<ul>
  <li><b>Routers Layer (Presentation / HTTP Transport):</b> Receives HTTP requests, parses path/query parameters, handles HTTP status codes, and delegates work to the Service Layer. Contains ZERO SQL queries or core business logic!</li>
  <li><b>Schemas Layer (Data Contracts):</b> Pydantic models defining input validation constraints and output JSON serialization models.</li>
  <li><b>Services Layer (Core Business Logic):</b> Implements domain rules, calculations, permissions, and orchestration. Completely decoupled from HTTP frameworks!</li>
  <li><b>Repositories Layer (Data Access):</b> Manages database interactions (SQLAlchemy, Redis, S3). Abstracts database queries behind clean Python methods.</li>
</ul>

<b>Benefits of Layered Clean Architecture:</b>
1. **Testability:** Business services and repository layers can be unit-tested in isolation without spinning up web servers.
2. **Maintainability:** Changing from PostgreSQL to MongoDB or changing web frameworks requires modifying only the Repository or Router layer—leaving business services untouched!

<b>Modular Endpoint Organization for Enterprise Applications</b><br/>

<b>1. What is an APIRouter?</b><br/>
An `APIRouter` operates as a mini-FastAPI application instance containing a subset of path operations.<br/>
<code>from fastapi import APIRouter</code><br/>
<code>router = APIRouter(prefix="/api/v1/parcels", tags=["Parcels"])</code><br/><br/>

<b>2. Key APIRouter Parameters:</b>
<ul>
  <li><code>prefix</code>: Common URL path prefix prepended to all routes in the module (e.g., <code>prefix="/api/v1/parcels"</code>).</li>

  <li><code>dependencies</code>: List of global dependencies applied automatically to **every** route in the router module (e.g., enforcing authentication across an entire router file!).</li>

<b>Abstracting Database Queries Behind Clean Interfaces</b><br/>
If your business logic services execute raw SQLAlchemy `select()` queries directly, switching database technologies or testing service logic requires complex database mocking setups. The **Repository Pattern** abstracts all data access logic behind a clean, object-oriented interface.<br/><br/>

<b>1. What is a Repository?</b><br/>
A **Repository** acts as an in-memory collection interface for database entities. The Service layer requests domain objects from the Repository without needing to know whether data is stored in PostgreSQL, SQLite, Redis, or an external web API.<br/><br/>

<b>2. Defining a Repository Class:</b>
<pre><code>class ParcelRepository:
    def __init__(self, db_session: Session):
        self.db = db_session

    def get_by_tracking_id(self, tracking_id: str) -> ParcelModel | None:
        stmt = select(ParcelModel).where(ParcelModel.tracking_id == tracking_id)
        return self.db.scalars(stmt).first()

    def create(self, parcel_model: ParcelModel) -> ParcelModel:
        self.db.add(parcel_model)
        self.db.commit()
        self.db.refresh(parcel_model)
        return parcel_model</code></pre><br/>

<b>Why use the Repository Pattern?</b>
1. **Centralized Queries:** Database queries are defined in one place, preventing SQL query duplication across multiple routes.
2. **Easy Unit Testing:** You can swap `SQLAlchemyParcelRepository` with a `MockParcelRepository` in unit tests without touching database code!

class Base(DeclarativeBase):
    pass

class ParcelModel(Base):
    __tablename__ = "parcels"
    id: Mapped[int] = mapped_column(primary_key=True)
    tracking_id: Mapped[str] = mapped_column(String(50), unique=True)
    weight_lbs: Mapped[float] = mapped_column(Float)

Base.metadata.create_all(engine)

# ------------------------------------------------------------------------------

    """Repository handling all database queries for ParcelModel entities."""
    def __init__(self, session: Session):
        self.session = session

    def get_by_tracking_id(self, tracking_id: str) -> ParcelModel | None:
        stmt = select(ParcelModel).where(ParcelModel.tracking_id == tracking_id)
        return self.session.scalars(stmt).first()

    def create(self, tracking_id: str, weight: float) -> ParcelModel:
        model = ParcelModel(tracking_id=tracking_id, weight_lbs=weight)
        self.session.add(model)
        self.session.commit()
        self.session.refresh(model)
        return model
