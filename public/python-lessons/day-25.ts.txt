<b>Pattern Matching and Structural Search in Python</b><br/>
Text processing goes far beyond simple string methods like <code>.find()</code> or <code>.replace()</code>. <b>1. What is a Regular Expression?</b><br/>

Searching for static patterns is helpful, but real data varies in length. A tracking number might have between 8 and 12 digits; a street address might contain multiple words; a postal code might be optional. **Quantifiers** define repetition, while **Anchors** restrict match locations.<br/><br/>

<b>1. Quantifiers (Defining Repetition Counts):</b>
<ul>

<b>2. Greedy vs. Lazy (Non-Greedy) Matching:</b><br/>

<b>1. Capturing Groups (Parentheses <code>(...)</code>):</b><br/>
Wrapping part of a regex pattern in parentheses creates a <b>Capturing Group</b>. Python extracts each grouped sub-pattern separately.<br/>
<code>pattern = r"([A-Z]{3})-(HUB)-(\\d{4})"</code>

Captured named groups can be accessed directly as a dictionary using <code>match.groupdict()</code>!

<b>3. Non-Capturing Groups (<code>(?:...)</code>):</b><br/>
When you need to group characters for quantification or logical OR checks without creating an extraction group, use a non-capturing group <code>(?:...)</code>.

<b>Conditional Matching Without Consuming Text</b><br/>
Standard regex patterns consume text as they match. However, you often need to match a token **only if it is followed or preceded by specific text**, without including that adjacent text in the match output. These are called **Lookaround Assertions** (zero-width assertions).<br/><br/>

<b>1. Lookahead Assertions (Inspecting Ahead):</b>
<ul>
  <li><b>Positive Lookahead <code>(?=...)</code>:</b> Matches text ONLY if followed immediately by the lookahead pattern.
    <br/><i>Example:</i> <code>r"\d+(?=\s*USD)"</code> matches digits ONLY if followed by `"USD"`, but does NOT include `"USD"` in the match!</li>
  <li><b>Negative Lookahead <code>(?!...)</code>:</b> Matches text ONLY if NOT followed by the lookahead pattern.
    <br/><i>Example:</i> <code>r"\d+(?!\s*USD)"</code> matches digits NOT followed by `"USD"`.</li>
</ul>

<b>2. Lookbehind Assertions (Inspecting Behind):</b>
<ul>
  <li><b>Positive Lookbehind <code>(?&lt;=...)</code>:</b> Matches text ONLY if preceded immediately by the lookbehind pattern.
    <br/><i>Example:</i> <code>r"(?&lt;=\$)\d+"</code> matches digits ONLY if preceded by a dollar sign <code>$</code>.</li>
  <li><b>Negative Lookbehind <code>(?&lt;!...)</code>:</b> Matches text ONLY if NOT preceded by the lookbehind pattern.</li>
</ul>

<b>Python Fixed-Width Lookbehind Rule:</b><br/>
In Python's built-in <code>re</code> module, lookbehind patterns must have a **fixed width** (e.g., <code>(?&lt;=\$|\#)</code> is valid, but variable-width <code>(?&lt;=a+)</code> raises an error).
