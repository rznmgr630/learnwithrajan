<b>Persistent Data Storage and Context Safety</b><br/>
In-memory variables, lists, and dictionaries disappear the moment a Python script finishes executing or the host server restarts. Real-world applications—such as delivery tracking engines, inventory managers, and e-commerce platforms—must read from and write to permanent disk storage. Python handles disk files using the built-in <code>open()</code> function paired with explicit <b>File Operating Modes</b>.<br/><br/>

<b>1. Common File Operating Modes:</b>
<ul>
  <li><code>"r"</code> (Read Mode - Default): Opens an existing file for reading text. Raises a <code>FileNotFoundError</code> if the target file does not exist.</li>
  <li><code>"w"</code> (Write Mode): Opens a file for writing text. <b>Warning:</b> If the file already exists, <code>"w"</code> completely truncates (deletes/overwrites) all existing contents without warning! If missing, it creates a new file.</li>
  <li><code>"a"</code> (Append Mode): Opens a file for writing text, appending new data to the very end of the file without overwriting existing contents. If missing, it creates a new file.</li>
  <li><code>"+"</code> (Read/Write Update Modifier): Combines reading and writing (e.g., <code>"r+"</code> opens for reading and writing without truncation; <code>"w+"</code> truncates and opens for reading/writing).</li>
</ul>

<b>2. Resource Leaks vs. Context Managers (<code>with</code> Statement):</b><br/>
Opening a file allocates a system file descriptor. Unclosed files cause memory leaks, file lock contention, and corrupted un-flushed write buffers.

def Stream_csv_records(file_path: str):
    """Streams CSV lines one-by-one without loading full file into memory."""
    with open(file_path, "r", encoding="utf-8") as f:
        header = f.readline().strip().split(",")
        for line in f: # Streams remaining data rows line-by-line
            parts = line.strip().split(",")
            if len(parts) == len(header):

    print(f"\n--- ADVANCED: Initializing Project Tree at [{base_root}] ---")

    created_folders = []

    return {
        "root_absolute_path": str(root_path),
        "folder_count": len(created_folders),
        "is_ready": root_path.exists()
    }

<b>Directory Iteration, Pattern Matching, and File Inspection</b><br/>
Real applications must organize files into directory structures, search for specific file patterns (such as finding all <code>.csv</code> manifest files generated today), and inspect file metadata (file size, modification timestamps, and permissions).<br/><br/>

<b>1. Searching Directories with Globbing (<code>.glob()</code> and <code>.rglob()</code>):</b>
<ul>
  <li><code>dir_path.glob(pattern)</code>: Searches the current directory for files matching a wildcard pattern (e.g., <code>"*.csv"</code> finds all CSV files in that folder).</li>
  <li><code>dir_path.rglob(pattern)</code>: Performs a **recursive search** through the current directory AND all nested subdirectories for matching files (e.g., <code>"**/*.log"</code> finds all log files in the entire sub-tree!).</li>
</ul>

<b>2. Inspecting File Metadata (<code>.stat()</code>):</b><br/>
Calling <code>path.stat()</code> returns an <code>os.stat_result</code> object containing physical metadata:
<ul>
  <li><code>st_size</code>: File size in bytes.</li>
  <li><code>st_mtime</code>: Last modification time as a UNIX epoch timestamp.</li>
  <li><code>st_ctime</code>: File creation time (or metadata change time on UNIX).</li>
</ul>

<b>3. Cleaning Up (Deleting Files and Directories):</b>
<ul>
  <li><code>path.unlink(missing_ok=True)</code>: Deletes a single file from disk.</li>
  <li><code>path.rmdir()</code>: Deletes an **empty** directory. (To delete non-empty directory trees, use <code>shutil.rmtree()</code>).</li>
</ul>

def prune_stale_log_files(target_folder: Path, max_age_days: float = 7.0) -> dict:
    \"\"\"
    Recursively scans target directory for .log files older than max_age_days
    and removes them safely using path.unlink().
    \"\"\"
    print(f"\n--- ADVANCED: Log Maintenance Audit for [{target_folder}] ---")

    if not target_folder.exists() or not target_folder.is_dir():
        return {"success": False, "error": "Invalid target directory."}

    current_time = time.time()
    max_age_seconds = max_age_days * 86400.0

    pruned_files = []
    retained_files = []

    for log_file in target_folder.rglob("*.log"):
        file_age_seconds = current_time - log_file.stat().st_mtime

        if file_age_seconds > max_age_seconds:
            # Unlink deletes file safely
            log_file.unlink(missing_ok=True)
            pruned_files.append(log_file.name)
            print(f"  PRUNED STALE LOG: {log_file.name}")
        else:
            retained_files.append(log_file.name)

    return {
        "success": True,
        "pruned_count": len(pruned_files),
        "retained_count": len(retained_files),
        "pruned_files": pruned_files
    }

test_log = base_dir / "old_system.log"
test_log.write_text("old log data", encoding="utf-8")

audit_summary = prune_stale_log_files(base_dir, max_age_days=0.0001) # Low age threshold for testing
print("Pruning Audit Summary:", audit_summary)
