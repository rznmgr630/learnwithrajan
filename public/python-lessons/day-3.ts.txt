Prefixing a string literal with <code>r</code> disables escape character processing. Backslashes are treated as literal characters.<br/>
<b>Primary Use Case:</b> Windows file paths (<code>r"C:\\Users\\Dispatch\\data"</code>) and regular expressions, where backslashes shouldn't be interpreted as escape sequences like <code>\\U</code> or <code>\\d</code>.<br/><br/>

<b>3. Unicode and Internationalization:</b><br/>
Python 3 strings support full Unicode out of the box. You can include foreign language characters, accents, and emojis directly in text or via Unicode hex escape codes (e.g., <code>"\\u2705"</code> evaluates to ✅).<br/><br/>

<b>4. Triple-Quoted Multiline Strings (<code>\"\"\"...\"\"\"</code>):</b><br/>
Triple quotes allow strings to span multiple lines, preserving line breaks and formatting. They are used for long textual content, templates, and docstrings.
