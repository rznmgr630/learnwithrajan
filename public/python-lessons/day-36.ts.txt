<b>Static Type Clarity in a Dynamically Typed Language</b><br/>
Python is dynamically typed: variable labels can point to an integer at one moment and be rebound to a string later. <b>Type Hints (PEP 484 & PEP 585)</b> solve this by adding explicit type annotations to variables, function parameters, and return types.<br/><br/>

<b>1. Crucial Rule: Type Hints Are NOT Enforced at Runtime!</b><br/>
Type hints are purely informational metadata for human developers, IDEs (VS Code, PyCharm), and static type analysis tools (like <code>mypy</code>). The Python interpreter completely ignores type annotations at runtime—passing a string into a function annotated with <code>weight: float</code> will <b>never</b> raise a runtime error on its own!<br/><br/>
