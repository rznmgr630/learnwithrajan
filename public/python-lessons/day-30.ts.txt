<b>Designing Professional Developer Interfaces</b><br/>

<b>1. The Core Anatomy of a CLI Command:</b><br/>
A standard production command follows this structural hierarchy:<br/>
<code>$ executable [global-flags] subcommand [positional-args] [options]</code><br/>
Example: <code>$ docker --debug run --detach -p 80:80 nginx:latest</code>
<ul>
  <li><b>Executable:</b> The root command or entry script (e.g., <code>docker</code>).</li>

  <li><b>Positional Arguments:</b> Mandatory values required for the operation (e.g., image name <code>nginx:latest</code>).</li>
  <li><b>Options/Flags:</b> Key-value flags modifying subcommand behavior (e.g., <code>--detach</code>, <code>-p 80:80</code>).</li>
</ul>

<b>2. The Golden Rules of CLI Design:</b>
1. **Self-Documenting Help Pages (`--help` / `-h`):** Every CLI executable and subcommand must provide automatic help menus explaining flag types and usage examples.
2. **Standard Unix Conventions:**
   - Single dash <code>-</code> for short single-character options (e.g., <code>-v</code>, <code>-f</code>).
   - Double dash <code>--</code> for full-word long options (e.g., <code>--verbose</code>, <code>--file</code>).

# ------------------------------------------------------------------------------

def resolve_effective_configuration(cli_args: argparse.Namespace, config_file_path: Path) -> dict:

    Hardcoded Defaults < Config File < Environment Variables < CLI Flags
    \"\"\"

        self.storage_file = storage_file

    def _ensure_storage(self):
        if not self.storage_file.exists():
            self.storage_file.parent.mkdir(parents=True, exist_ok=True)
            self.storage_file.write_text(json.dumps({}), encoding="utf-8")

    def _load_data(self) -> dict:
        try:
            return json.loads(self.storage_file.read_text(encoding="utf-8"))
        except Exception:

            "destination": destination,
            "weight_lbs": weight,
            "status": "QUEUED"
        }
        data[tracking_id.upper()] = record
        self._save_data(data)
        return record

        record = data.get(tracking_id.upper())
