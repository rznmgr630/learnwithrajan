<b>Cryptographic One-Way Transformations for Credential Security</b><br/>
Storing plain-text passwords in a database is one of the most critical security vulnerabilities a developer can commit. When databases are compromised, plain-text passwords expose users across every service where they reuse credentials. Password security relies on <b>Cryptographic Password Hashing</b>.<br/><br/>

<b>1. Hashing vs. Encryption:</b>
<ul>
  <li><b>Encryption (Two-Way):</b> Converts text to ciphertext using a key, which can be decrypted back to plain text using the secret key.</li>
  <li><b>Hashing (One-Way):</b> A mathematical function that converts arbitrary data into a fixed-length string hash. It cannot be mathematically inverted to retrieve the original password!</li>
</ul>

<b>2. The Role of Cryptographic Salt:</b><br/>
Attackers use pre-computed tables of billions of common password hashes (termed **Rainbow Tables**) to reverse raw hashes instantly. A **Salt** is a unique, randomly generated byte sequence appended to every password *before* hashing. Salting ensures that two users with the identical password <code>"Password123!"</code> result in completely different hashes in the database, rendering Rainbow Tables useless!<br/><br/>

<b>3. Modern Password Hashing Algorithms:</b><br/>
Fast hash functions like MD5, SHA-1, or SHA-256 are designed for speed and are completely unsafe for passwords because modern GPUs can compute billions of SHA-256 hashes per second.
<ul>
  <li><b>Argon2id (Winner of Password Hashing Competition):</b> The current gold standard. Configurable for memory cost, time cost, and parallelism.</li>
  <li><b>Bcrypt:</b> The battle-tested industry standard featuring an adjustable work factor (cost factor) to slow down brute-force hardware attacks.</li>
</ul>

<b>Stateless Cryptographic Claims and Token Lifecycles</b><br/>
In stateless RESTful architectures, servers do not store session IDs in memory. Instead, user authentication is managed via **JSON Web Tokens (JWT)** (RFC 7519). A JWT is an open standard string that securely transmits JSON-encoded claims between two parties.<br/><br/>

<b>1. The 3 Parts of a JWT String (separated by dots `.`)</b>:
<ul>
  <li><b>Header (Base64URL):</b> Specifies token type (`JWT`) and signing algorithm (e.g., `HS256` or `RS256`).</li>
  <li><b>Payload (Base64URL):</b> Contains user claims and metadata (e.g., `sub` user ID, `exp` expiration timestamp, `role`).
    <br/><i>Warning:</i> Payload claims are Base64 encoded, NOT encrypted! Never store passwords or credit card numbers in a JWT payload!</li>
  <li><b>Signature:</b> A cryptographic signature computed by hashing `Header + Payload + SecretKey`. Prevents clients from tampering with claims!</li>
</ul>

<b>2. Access Tokens vs. Refresh Tokens Architecture:</b>
<ul>
  <li><b>Access Token:</b> Short-lived token (e.g., 15-minute expiration) passed in `Authorization: Bearer <token>` headers to access protected endpoints.</li>
  <li><b>Refresh Token:</b> Long-lived token (e.g., 7-day expiration) stored securely (e.g., HTTP-only cookie). Used exclusively to request a new Access Token when the short-lived token expires, limiting the window of risk if an access token is intercepted.</li>
</ul>

import jwt
from datetime import datetime, timedelta, timezone

# ------------------------------------------------------------------------------
# Production Setup: PyJWT Configuration
# ------------------------------------------------------------------------------

SECRET_KEY = "SUPER_SECRET_PRODUCTION_SIGNING_KEY_CHANGE_IN_PROD"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 15


def create_access_token(data: dict, expires_delta: timedelta | None = None) -> str:
    """Generates a signed JWT Access Token containing user claims and expiration."""
    to_encode = data.copy()

    now = datetime.now(timezone.utc)
    expire = now + (expires_delta or timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES))

    # Standard JWT claims: exp (expiration), iat (issued at)
    to_encode.update({"exp": expire, "iat": now})

    # Sign token with secret key
    encoded_jwt = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
    return encoded_jwt

    try:

        return payload
    except jwt.ExpiredSignatureError:
        raise PermissionError("HTTP 401: JWT token has expired.")
    except jwt.InvalidTokenError:
        raise PermissionError("HTTP 401: Invalid or tampered JWT token signature.")
